# ESL Battleship

This is a spin on the classic game Battleship, intended to use English questions for ESL learners instead of the usual grid coordinates.  

The game is intended to be played on iPads in pairs.

This is still an early work-in-progress build. More information will be added in the future.  

The initial design and vocabulary are based on a paper version from here: [https://www.altopedia.net/activities/1023-does-he-she](https://www.altopedia.net/activities/1023-does-he-she)

Ideally, future versions will support swapping wordlists for different types of grammar.
